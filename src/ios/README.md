# Azahar iOS App

Native SwiftUI frontend for the Azahar 3DS emulator, equivalent to the Android
Kotlin frontend (`src/android/`).

## Architecture

The port mirrors the Android app structure:

| Android | iOS |
|---------|-----|
| JNI layer (`src/android/.../jni/`) | ObjC++ bridge (`src/ios/AzaharBridge/`) |
| `NativeLibrary.kt` | `azahar_ios.h` (C API) |
| `native.cpp` | `ios_bridge.mm` |
| `EmuWindow_Android` | `EmuWindowIOS` |
| `NDKMotionFactory` | `IOSMotionFactory` (CoreMotion) |
| NDK Camera | AVFoundation Camera (stub) |
| `Config` / `default_ini.h` | `ConfigIOS` / `default_ini_ios.h` |
| `InputManager` | `InputManagerIOS` |
| Kotlin Activities/Fragments | SwiftUI Views |
| Android XML layouts | SwiftUI declarative views |
| Choreographer `doFrame()` | `CADisplayLink` → `az_present_frame()` |

## Building

Requires Xcode 15+, macOS 14+, iOS 18+ deployment target, and all submodules
initialized:

```bash
git submodule update --init --recursive
cmake -S . -B build-ios -G Xcode \
    -DCMAKE_SYSTEM_NAME=iOS \
    -DCMAKE_OSX_DEPLOYMENT_TARGET=18.0 \
    -DCMAKE_OSX_ARCHITECTURES=arm64 \
    -DENABLE_QT=OFF \
    -DENABLE_LIBRETRO=OFF \
    -DENABLE_TESTS=OFF
cmake --build build-ios --config Release
```

## Key Design Decisions

- **Vulkan via MoltenVK only** — OpenGL ES is deprecated on iOS; the `WindowSystemType::MacOS`
  path in `vk_platform.cpp` already creates a `VkSurfaceKHR` from a `CAMetalLayer`.
- **SwiftUI** chosen over UIKit to match the declarative style of the Android Jetpack Compose
  frontend.
- **Pure C API** (`azahar_ios.h`) at the bridge boundary — no C++ leaks into Swift via a
  bridging header. Callbacks from C++ to Swift use function pointers (matching the
  Android JNI `CallStatic*Method` pattern).
- **`src/common/setting_keys.h`** generated by CMake as usual; the `default_ini_ios.h`
  template must declare every key not in the omitted list to satisfy the `Config::Reload()`
  validation assert.
- **Screen rotation** is communicated from Swift → `az_set_portrait_mode(bool)` → shared
  atomic used by `EmuWindowIOS::OnFramebufferSizeChanged()` (avoids UIKit calls from the
  emulation thread).

## Completed Features

- **Camera backend**: `AVCaptureSession`-based `Camera::IOS::Factory` with BGRA→RGB565 conversion
  (mirrors Android's NDK camera). Falls back to blank frames if permission denied.
- **Applets**: Blocking C++/Swift synchronization for `SoftwareKeyboard` and `MiiSelector`.
  Validation exposed via `az_swkbd_submit()`; microphone permission via `CheckMicPermission()`.
- **MFi gamepad**: `GamepadManager` maps `GCExtendedGamepad` buttons/sticks/triggers to the C
  bridge (A/B/X/Y, D-Pad, L/R, ZL/ZR, Circle Pad, C-Stick, Start, Select, Home).
- **Update checker**: async GitHub releases API call; shows version + download link when new
  version available.
- **SMDH loader**: `SMDHLoader` extracts game titles and metadata from ROM files.
- **System files view**: lists system title status, AES key check, console unlink.
- **About / Licenses**: version info, GPLv2 text, third-party library credits, project links.
- **CI integration**: `.github/workflows/ios-build.yml` — builds on macOS with Ninja + ccache.
- **Localization**: `Localizable.xcstrings` with 10 languages (German, Spanish, French, Italian,
  Japanese, Korean, Portuguese, Russian, Simplified Chinese, Traditional Chinese).

## What Remains for Full Parity

- **Multiplayer UI**: C API wired into multiplayer.cpp, but the full lobby/chat Swift views need
  room member lists, chat message stream, and moderator actions completed.
- **Amiibo file picker**: the `az_load_amiibo` bridge works; needs a SwiftUI document picker
  wired into the emulation menu.
- **CIA install progress**: `Service::AM::InstallCIA` progress reporting to SwiftUI UI.
- **NetPlay**: room list populates but actual room join/create flow not yet tested end-to-end.
- **Hotkey system**: volume buttons, swipe gestures for layout cycling, customizable hotkeys.
- **Performance overlay**: in-emulation FPS/percent display (the C bridge has `az_get_perf_stats`).
- **Game icon caching**: SMDH extraction works but game list should cache icons to avoid re-reading.
